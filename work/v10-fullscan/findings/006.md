# chunk 006

Scope: `v10/usr/blit/m/src/mip/` (20 files) and `v10/usr/blit/m/src/mld/` (18 files).
These are the two halves of the Blit/DMD **m68000 cross toolchain hosted on the VAX**: `mip`
is the machine-**independent** part of a pcc-derived C compiler plus `sty`, its
machine-description-to-table generator; `mld` is the m68000 cross-linker. All 38 files are
text; none is binary.

## install destinations

| mip/makefile:79-80 | `/ccom` | the built pass-1/pass-2 compiler binary `comp` | `cinstall: install` / `	cp comp $(INSTALL)` |

| mld/main.c:22 | `/usr/blit/lib` | second built-in library directory searched for `-l` | `	append(&syslibs, "/usr/blit/lib");` |

The two `main.c` rows are runtime path requirements, not `cp` lines, and they are load-bearing:
`mld/doarg.c:184` spells out the filename it forms —

```
	x = cat4(lib, "/lib", s, ".a");
```

so `mld -lc` opens `/usr/lib/libc.a` then `/usr/blit/lib/libc.a`. The m68000 libraries **must**
be installed under one of those two names. There is no `-L`: see trap **N**.

`SFILES` and `MFILES` are defined at mip/makefile:10-13 —

```
MFILES= $M/common $M/cgram.y $M/sty.y $M/manifest $M/mfile1 $M/mfile2 \
	$M/pftn.c $M/scan.c $M/comm1.c $M/trees.c $M/optim.c $M/xdefs.c \
	$M/reader.c $M/cgen.c $M/cost.c $M/allo.c $M/match.c $(SDB)
SFILES=	g stin local.c local2.c macdefs
```

`MFILES` is exactly this chunk's mip directory (minus the generated `cgram.c`); `SFILES` is
the machine-dependent set, and **none of those five files exists here**.

## documented build steps

### mip — the machine-independent compiler (`comp`)

- Knobs: `M=.` (source dir, mip/), `I=` (extra include flags), `CFLAGS=-O`, `CC=cc`,
  `SDB=$M/sdb.h`.
- Default target `comp` (makefile:14-16) links `$(OFILES)` and renames: `mv a.out comp`.
  `OFILES` (makefile:8-9) is `cgram.o xdefs.o scan.o pftn.o trees.o optim.o local.o reader.o
  local2.o match.o allo.o comm1.o table.o cost.o cgen.o`.
- **Required ordering**: `sty` before `table.c` before `table.o` —
  `table.c: sty stin` / `	sty <stin >table.c` (makefile:42-43). And `$M/cgram.c: $M/cgram.y`
  / `	yacc $M/cgram.y` / `	mv y.tab.c $M/cgram.c` (makefile:35-37) before `cgram.o`.
- **Tools beyond cc/as/ld**: `yacc` (twice — cgram.y and sty.y), `lint` (`lintall`,
  makefile:59-60, `lint -hpv …`), `push` (a remote-copy command, makefile:85 and :91),
  `regress` (makefile:96-97, `stout: comp` / `	regress >stout`), and `sty` itself.
- **Flag exception, deliberate**: every object rule passes `$(CFLAGS)` except `table.o`
  (makefile:40-41), which is compiled unoptimised: `$(CC) -c $I table.c`.
- The `fort` target (makefile:61-78) builds a Fortran front end from `$M/fort.c`,
  `$M/freader.c`, `$M/fallo.c`, `$M/fmatch.c`, `$M/ftable.c`, `$M/flocal2.c`, `$M/fcomm2.c` —
  none present — and uses literal `cc`, not `$(CC)`, on every line.
- `clean` (makefile:56-58) removes `comp stout *.o mout sty table.c`. `mout` is produced by
  no rule in this makefile.
- Conditional compilation the sources expect from `macdefs`: `SDB`/`STABS` (manifest:327-329,
  optim.c:732-945, match.c:429-434, pftn.c:378-398), `NOSHORT`/`NOLONG`/`NOFLOAT`/`ONEFLOAT`
  (manifest:5-25, mfile2:22-53), `STACK`, `TWOPASS`, `NONEST`, `BACKAUTO`, `BACKARGS`,
  `RTOLBYTES`, `LONGFIELDS`, `ARGSRET`/`STATSRET`/`ARGALLRET`, `MEMONLY`, `TWOPTRS`, `XI`,
  `ASSYCOMMENT`, `LINT`, `NODBG`, and about thirty `MY*` override hooks.

### sty — the machine-description compiler (mip/sty.y)

- Purpose stated in its own first line, sty.y:1: `/*	This program turns machine descriptions
  into a table.c file */`, with the input language documented at sty.y:3-44 — the type
  shorthand letters (`c i s l p P t v ux f d`), the builtin cost names (`NONAME`, `CONVAL n`,
  `NCONVAL n`, `POSRANGE n`, `SGRANGE n`) and the needs/results codes (`$P $< $> $L $R
  $1,2,3 $C $N $A $[ $] $l $r`).
- sty.y:39-44 is an ordering rule for the machine description that reads it, not for the build:
  `When several templates match with equal cost, the first is chosen.` … `Moral:  $N templates
  should be cheaper or should preceed $L, $1, etc.`
- Built at makefile:17-20: `yacc $M/sty.y` / `cc $I $(CFLAGS) -o sty y.tab.c` / `rm y.tab.c`.
  Note literal `cc`, and note that `sty` depends on `macdefs` too (makefile:17) — the table
  generator is itself per-machine.
- Table-size ceilings sty enforces: `NOPTB 400` templates (sty.y:69-71, `yyerror("too many
  templates")`), `NSTRING 10000` (sty.y:86-88), `NSTYSHPS 4000` shapes (sty.y:90-92).

### mld — the m68000 cross-linker

- makefile:1-3 `HDR=a.out.h mld.h list.h`, `SRC=doarg.c doto.c glob.c list.c main.c output.c
  reloc.c str.c sym.c`, matching `OBJ`.
- Default target: `$(CC) $(CFLAGS) -o mld $(OBJ) $X` (makefile:7), with `CFLAGS=-g`
  (makefile:5) — debug, **not** `-O` — and `X=` (makefile:4) an empty hook for extra objects.
  There is no `CC=` line: it relies on make's built-in `CC` macro.
- `$(OBJ):	$(HDR)` (makefile:10) is the whole dependency graph.
- **Host precondition asserted in the source**, mld.h:1-3:
  ```
  #ifndef vax
  this file for vax to m68000 cross loading
  #endif
  ```
  A deliberate syntax error unless `vax` is predefined. `mld` builds only on a VAX.
- Auxiliary targets need Blit-era tools: `list:` / `	pr $(HDR) $(SRC) | can` and `pp:` /
  `	pp $(HDR) $(SRC) ^ dcan` (makefile:11-14) — `can`/`dcan` are canvas printers, `pp` a
  pretty-printer, and `^` in the last rule is not sh pipe syntax.
- Output formats: default `0407` (`struct exec outhdr = {0407};`, doarg.c:13), `0406` under
  `-M` (doarg.c:141-144). Inputs accepted: `0406`/`0407` objects and `ar` archives; `0410`,
  `0411`, `0413` are a hard error (doarg.c:44-48).

## contradictions and traps

**A. `M=.` contradicts the committed generated file.** mip/makefile:3 says `M=.`, but
mip/cgram.c — the checked-in yacc output — carries `# line` directives naming
`"../mip/cgram.y"` (cgram.c:51, :62, :67 and every action thereafter). The real build ran from
a *sibling machine-dependent directory* with `M=../mip`. With `M=.` the rule at makefile:87-89
recurses into itself: `to70:: $(MFILES)` / `	cd $M; make to70`.

**B. `make` in mip/ cannot build anything.** Every `.c` here opens with `# include "mfile1"` or
`# include "mfile2"`, and both of those open with `# include "macdefs"` (mfile1:1-2,
mfile2:1-2). `macdefs` is not in this directory. Nor are `local.c`, `local2.c`, `stin`, `g`,
`table.c`, `fort.h`, `regress`, or any of the seven `f*.c` Fortran sources the makefile names.
mip/ is the machine-independent half only; the machine-dependent half (which supplies
`macdefs`, the register names `rnames[]`, `NRGS`, `SZ*`/`AL*`, `local.c`, `local2.c`, `stin`)
lives elsewhere. Not one file in this directory compiles standalone.

**C. `table.o` must not be optimised.** mip/makefile:41 is `$(CC) -c $I table.c` where every
other object rule is `$(CC) -c $I $(CFLAGS) …`. A "normalise the flags" edit changes the build.

**D. Three names for one program.** The makefile builds `comp` (makefile:16), installs it as
the file `/ccom` (makefile:2, :80 — a bare root-level path, not `/lib/ccom`), and the binary
identifies itself to the user as `ccom` — scan.c:137:
```
						fprintf(stderr, "ccom:can't open %s\n", argv[i]);
```

**E. Four of mld/'s eighteen files are not part of mld.** `SRC`/`OBJ` (mld/makefile:2-3) omit
`ds.c`, `nds.c`, `e.c` and `mnm.C`. Nothing builds them and nothing installs them.

**F. `ds.c` and `nds.c` are the same file; one is stale.** Both are 792-line m68000
disassemblers. `diff` reports exactly four differing lines:
```
2,5c2,5
< #include "../a.out.h"          > #include "a.out.h"
< #include "../ld.h"             > #include "mld.h"
< #include "../sym.h"            > #include "sym.h"
< #include "../optim.h"          > #include "optim.h"
78c78 / 622c622
< 	long x;                     > 	unsigned long x;
```
`nds.c` ("new ds") is retargeted to mld's own headers and carries the unsigned fix, so `ds.c`
is the stale copy. Neither is referenced by the makefile.

**G. Neither disassembler can compile as shipped.** `sym.h`, `optim.h` and `ld.h` exist nowhere
under `v10/usr/blit`, and `../a.out.h` — i.e. `v10/usr/blit/m/src/a.out.h` — does not exist
either. The only `a.out.h` files in the whole blit tree are
`v10/usr/blit/include/a.out.h`, `v10/usr/blit/m/src/mld/a.out.h` and
`v10/usr/blit/src/joff/host/a.out.h`.

**H. Two incompatible `struct reloc` definitions in one directory.** mld/a.out.h:36-42 declares
`rtype:4, r2wds:1, rpc:1, runused:1, rnum:9`, and defines no `A_MAGIC1`. ds.c/nds.c use
`txtr[i].rext` and `txtr[i].rseg` (reltxt(), lines 717-751), the segment constants
`ABS/TEXT/BSS/COMM/DATA`, and `hdr.a_magic != A_MAGIC1` (line 44) — all from a *different*
a.out.h. Reading mld/a.out.h and assuming it serves the whole directory is wrong; mld itself
uses `rtype & N_TYPE` (reloc.c:29, :34) against the local header.

**I. `mld/sdb.H` is a stale copy of `mip/sdb.h`.** mip/sdb.h carries three entries sdb.H lacks
(`S_NARGS 0x20`, `S_TYID 0x21`, `S_DIM 0x22` — sdb.H stops at S_NARGS), and the trailing macro
is spelled differently: mip/sdb.h:33 `#define STABTYPE 0xff` versus mld/sdb.H:29
`#define STABTYPES 0xff`. Nothing in mld includes either; `mip`'s copy is the live one
(`SDB=$M/sdb.h`, makefile:7). Two files, one letter apart in a case-folding-hostile checkout.

**J. `mld/mnm.C` is NOT a copy of `v10/usr/blit/m/src/mnm.c`.** `mnm.C` is a 24-line stdin-only
symbol dumper (`fstat(0,…); read(0,…)`, one printf). `../mnm.c` is a 244-line
`mnm [-goprun] [name ...]` that walks archives via `ar.h`, honours four magic numbers
(`A_MAGIC1..4`) and sorts. Same family of name, different programs. The uppercase `.C` is the
tape's own spelling — there is no lowercase `mnm.c` in mld/, so this is not a `u_`-style
case-collision rename and must not be "corrected" to one.

**K. `mld/e.c` is a jerq graphics demo, not linker code.** Ten lines: `#include <jerq.h>`,
`jinit()`, `rectf(&display, Drect, F_XOR)`, `elarc(…)`, `sleep(300)`. It needs the
`/usr/jerq/include` headers that mld's makefile never supplies, and it is not in `SRC`.

**L. mip/cgram.c is a committed artefact the build overwrites.** `$M/cgram.c: $M/cgram.y` /
`	yacc $M/cgram.y` / `	mv y.tab.c $M/cgram.c` (makefile:35-37) writes back into the source
directory. It is currently *consistent* with cgram.y — its `# line` markers 108, 127 and 817
land exactly on `# include "mfile1"`, `static int fake = 0;` and `%%` — so it is not stale, but
building with a different yacc rewrites a committed file (and loses the `../mip/` line
directives that are the evidence for trap **A**).

**M. `-DYYDEBUG` cannot work.** cgram.c:517-519 is `#ifdef YYDEBUG` / `#include "y.debug"` /
`#endif`, and `y.debug` is neither present in mip/ nor produced by any rule.

**N. `mld` has no `-L`, so the library paths are not negotiable.** main.c:6-7 comments
`lists of library directories. / usr searched first` and `dolib()` (doarg.c:170-177) searches
`usrlibs` before `syslibs` — but `options()` (doarg.c:87-168) implements
`o b B D d u l M m r v R s` and **no `L`**, and nothing ever appends to `usrlibs`
(main.c:20 sets it empty and leaves it). Only the two hardcoded `syslibs` entries are ever
searched. Same shape as V10's own `ld` hardcoding `-lX` to `/lib`, `/usr/lib`,
`/usr/local/lib`.

**O. mld relies on Unix "common" symbol merging; four globals are defined twice.**
`char flg[128];` in both main.c:10 and doarg.c:8; `char *outfile` in main.c:8 (with
initialiser `"a.out"`) and doarg.c:10 (without); `struct exec outhdr` in doarg.c:13 (with
initialiser `{0407}`) and output.c:7 (without); `int dataorg` in doarg.c:11 and glob.c:8. This
links only where tentative definitions collapse into a common block. It also means the `0407`
default and the `"a.out"` default each live in exactly one of the two copies.

**P. mld.h re-declares all of list.h.** mld.h:21-25 repeats the `list` typedef and
`extern list *mustuse, initlist;` verbatim from list.h:1-5. `list.c` includes only list.h;
every other file includes only mld.h. Including both in one translation unit is a duplicate
typedef.

**Q. mip/makefile's `fort` sub-targets depend on objects, not sources.** makefile:66-77 reads
`freader.o: reader.o`, `fallo.o: allo.o`, `fmatch.o: match.o`, `ftable.o: table.o`,
`flocal2.o: local2.o` — each recipe compiles a *different* file (`$M/freader.c` etc.) from the
prerequisite named. Nothing regenerates these when their own sources change.

**R. Every table size here is overridable, so this directory does not decide them.** All are
`# ifndef`-guarded: `SYMTSZ 750` (manifest:296-298), `TREESZ 350` / `1000` under `FORT`
(manifest:302-308), `NSHP 20` (mfile2:220-222), plus `BCSZ 100`, `DIMTABSZ 800`, `PARAMSZ 150`,
`ARGSZ 50`, `SWITSZ 250`, `NCHNAM 8`, `NINS 300`. `macdefs` — the missing file — can change any
of them.

**S. Cosmetic tape bug, will show up in any diff against a "fixed" copy.** mip/xdefs.c:170-171
gives `GE` and `GT` the same printed name:
```
	GE, ">", BITYPE|LOGFLG,
	GT, ">", BITYPE|LOGFLG,
```
so diagnostics print `>` for `>=`. Leave it; it is what the tape says.

## files with no build contribution

disagreement with anything else:
